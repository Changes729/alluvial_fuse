# 2026-11-12 更新日志

**01 基本功能描述**

实现了用户态 overlay file system.

基本使用：`alluvial_fuse --mount [mount/point]`
默认 upper 目录会在 `.local/share/alluvial_fuse/xxx` 创建

其他参数包括
- `--lower [lower/dir]`：指定 lower 层目录
- `--upper [upper/dir]`：指定 upper 层目录
- `--workdir [work/dir]`：指定工作目录
- `-o`： 透传 libfuse 参数

和普通 overlay 不一样，我们的挂载目录就是 lower 目录。这是创新点。也是为了防止用户随意修改 lower 的内容。
